# Übersetzungssätze für den Reiter „Sätze“
# ==========================================================================
# Nur Wörter aus vokabel_base.json.  Die Lektion eines Satzes berechnet
# saetze.py selbst (spätestes Wort / spätere Form, z. B. Perfekt ab L8);
# die Zahl hinter L ist nur die Mindestlektion für die GRAMMATIK, die sich
# nicht an einzelnen Formen ablesen lässt (Dativ L3, Ablativ L4, Genitiv L5,
# AcI L9, Relativsatz L11, Reflexivpronomen L12 ...).
#
#   -- L3            die folgenden Satzpaare sind EINZELSÄTZE
#   == L4 Titel      die folgenden Satzpaare bilden EINEN TEXT
#   la: lateinischer Satz
#   de: deutsche Übersetzung | weitere richtige Übersetzung | ...
#       Wörter in (Klammern) sind erlaubt, aber nicht nötig.
#
# Prüfen:  py -3 programm/saetze.py
# ==========================================================================
